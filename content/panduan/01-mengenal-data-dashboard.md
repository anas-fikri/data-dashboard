Data Dashboard menggantikan dashboard Excel: data diunggah sekali, lalu siapa pun yang diberi akses bisa melihat angka terbaru tanpa membuka file besar atau takut rumus rusak.

## Alur kerja singkat

1. **Dataset** — tempat data Anda. Buat dataset, lalu unggah file **.xlsx** atau **.csv** sampai **1 GB**.
2. **Skema** — aplikasi mendeteksi nama dan tipe tiap kolom. Periksa dan perbaiki bila perlu.
3. **Dashboard** — susun widget (angka, batang, garis, pai, tabel) dari dataset itu.
4. **Bagikan** — undang rekan sebagai _Hanya lihat_ atau _Bisa mengedit widget_, atau bagikan ke seluruh organisasi.

## Peran di aplikasi

- **Pemilik data** — membuat dataset, mengunggah file, mengatur skema, menyusun dan membagikan dashboard.
- **Editor** — mengubah widget dan tata letak dashboard yang dibagikan kepadanya.
- **Viewer** — melihat dashboard, memakai filter, dan mengekspor data.
- **Admin** — mengelola pengguna dan menulis panduan.

Satu orang bisa punya beberapa peran sekaligus. Halaman **Panduan** menampilkan tab sesuai peran Anda.

## Navigasi

- Menu kiri: **Beranda**, **Dataset**, **Dashboard**, **Panduan** (dan **Admin** untuk admin). Di ponsel, buka lewat tombol menu di kiri atas.
- Tombol **Bantuan** di kepala halaman dataset, skema, dan dashboard (bagi yang bisa mengeditnya) membuka panduan untuk halaman itu tanpa meninggalkan pekerjaan Anda.
- Menu akun (inisial nama di kanan atas): **Keamanan** untuk mengganti password, dan **Keluar**.
