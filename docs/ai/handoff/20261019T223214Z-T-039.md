## Hitung kuota dari byte data yang benar-benar tersimpan

Kuota per pengguna kini dari byte yang benar-benar tersimpan: segmen unik terujuk versi hidup (rawBytes/typedBytes dicatat saat ingest/recast/pemetaan menulis file; segmen lama diukur pemeriksaan malam) + file sumber yang masih tersimpan (FAILED hanya bila pernah UPLOADED) + ukuran UPLOADING, satu fungsi userUsage untuk init unggah dan transfer admin. Init memproyeksikan file + ±1,2× parquet dan menolak QUOTA_EXCEEDED 'terpakai X dari Y, file ini Z (±W setelah diproses)' sebelum byte pertama; masa transisi QUOTA_GRACE_DAYS sejak migrasi T-039 hanya memperingatkan yang masih muat menurut hitungan lama. Banner pengguna ≥ 80% di setiap halaman (cache 60 detik), laporan scripts/quota-report.mjs, compose kini meneruskan kuota. Diverifikasi unit (rumus, proyeksi, transisi, banner, ukuran tercatat, backfill) dan e2e uploads 9/9, admin 6/6, ingest 4/4.
