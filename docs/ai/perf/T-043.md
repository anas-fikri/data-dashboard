# T-043 — Lihat data: mekanika gulir 10 jt baris dan ukuran chunk rute

- Tanggal: 2026-10-20, container cloud (Linux), dev server Next 16 (Turbopack), Node 22.23.3.
- Komponen: AG Grid Community 36.2.0 (dipin), semua mitigasi ADR-0007 aktif bersama (wheelfix, sentinel
  "Akhir data" + fixbottom, focusguard, "Ke baris" `'middle'` + fokus DOM, Ctrl/Cmd+Home/End sendiri,
  `styleNonce`).
- Engine: Chromium (headless shell 1248), Firefox 1555, WebKit 2370 (Playwright 1.64).

## Cara mengukur

- Mekanika: `npx playwright test --project=data-view-scroll --no-deps` (dan `-firefox`, `-webkit`). Halaman dan
  sheet sungguhan (CSV kecil lewat worker); respons `POST /api/sheets/:id/rows` diganti baris sintetis berjumlah
  10.000.000 (versi/revisi dari respons asli), sehingga yang diukur klien. Jalur server 10 jt baris sendiri sudah
  diukur di T-041/T-042 (p95 35 ms tanpa urut).
- Chunk: `npx next build && node scripts/measure-grid-chunk.mjs` (gzip level 6, KiB = 1.024 byte).

## Batasan

- Seret thumb diuji lewat `scrollTop` maksimum, bukan seret mouse sungguhan (scrollbar headless overlay).
- Sentuh (≤ 15 baris per usapan 300 px) dan trackpad nyata tidak diuji di container; mode paging blok sentuh belum
  dibangun (P-16/T-048).
- Pembaca layar NVDA/VoiceOver (gerbang ADR-0007 `accepted`) belum diuji: butuh perangkat Windows/macOS pemilik.
