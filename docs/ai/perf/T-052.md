# T-052 — durasi unggahan periode vs unggahan ke dataset kosong (AC1)

Syarat AC1: file April yang sama, diproses sebagai unggahan periode ke dataset Jan–Mar (cast skema aktif,
penetapan periode, segmen, rencana), ≤ 1,2 × durasi unggahan file itu ke dataset kosong (inferensi).

Skrip: `npx tsx --conditions=react-server scripts/perf-period-ingest.ts <baris> <ulang>` — kedua jalur
dijalankan bergantian di proses yang sama (runIngest vs runPeriodIngest), database palsu in-memory, storage
lokal (hard link), parser + DuckDB sungguhan. Bukan bagian `npm run check`.

Mesin: kontainer cloud 4 vCPU, Node 22.23.3, DuckDB 2 thread (bawaan worker). CSV 12 kolom (teks, tanggal,
angka id-ID, desimal), satu periode (April 2026).

| Baris | Ukuran | Dataset kosong (median) | Unggahan periode (median) | Rasio | Lulus |
|---|---|---|---|---|---|
| 300.000 | 20,6 MB | 16,73 s (16,68 / 16,73 / 17,54) | 17,10 s (17,10 / 16,61 / 17,33) | 1,02 | ya |
| 1.000.000 | 68,6 MB | 50,68 s (50,30 / 50,68 / 53,63) | 52,00 s (51,83 / 52,21 / 52,00) | 1,03 | ya |

Mengapa murah: satu periode tanpa baris tanpa tanggal memakai raw file utuh sebagai raw segmen (tanpa
salinan) dan profil yang sama untuk vonis cast + profil tersimpan; tambahan hanya query penetapan periode
(cast satu kolom) dan pemeriksaan tanggal ∈ periode pada file typed. Periode Jan–Mar tidak dibaca sama
sekali (hanya metadata manifest + HEAD kunci).
