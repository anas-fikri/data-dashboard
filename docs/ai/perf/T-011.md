# T-011 — Perf widget tabel (1 juta baris)

- **Tanggal:** 2026-10-13 (diukur ulang pada kode akhir: materialisasi terlambat + urutan teks seperti Excel).
- **Mesin:** Apple M4 (10 core), RAM 16 GB, SSD lokal; Node 26; DuckDB 1.5.6. Mesin query: `memory_limit` 1 GB, `threads` 2, 2 query per user, sandbox sama dengan produksi. Dev server dan worker ikut berjalan (load average ± 3).
- **SQL halaman** (`src/features/query/table.ts`): `count(*)` dengan filter (di-cache terpisah dari halaman), lalu halaman 100 baris dengan **materialisasi terlambat** — pengurutan + OFFSET hanya membawa kolom urut dan `_row`, isi 100 baris diambil sesudahnya lewat `_row`. Kolom teks diurutkan `COLLATE "nocase.noaccent"` (seperti Excel), pemecah seri `_row`. Halaman di luar data dijepit ke halaman terakhir. count + halaman berbagi satu batas waktu.

## A. Tabel sempit — CSV 1 juta baris lewat ingest sungguhan

- **Fixture:** `npx tsx scripts/make-fixture.ts --kind csv --out tests/fixtures/perf/1jt-baris.csv --rows 1000000 --cols 10 --text-ratio 0.3 --unique-ratio 0.2 --number-locale id --delimiter ";"` — 120 MB, dihapus setelah diukur.
- **Perintah:** `npx tsx --conditions=react-server scripts/perf-widget-table.ts tests/fixtures/perf/1jt-baris.csv` — ingest (raw + typed), lalu widget tabel 6 kolom pertama lewat `runWidgetQuery` (sama dengan `/api/query { widgetId, page, sort }`), **tanpa cache hasil**; 8 skenario × 5 permintaan.

## Lolos/tidak terhadap AC

- **AC 5** (widget tabel atas sheet 1 juta baris, sort + pindah halaman, respons < 2 detik): **lolos** — tabel sempit maks 99 ms, tabel lebar 20 kolom teks maks 791 ms, keduanya tanpa cache hasil.

## Catatan

- Di aplikasi, halaman/urutan yang sama dilayani cache hasil (kunci = spec widget + urutan + halaman + revisi skema); total baris di-cache terpisah sehingga pindah halaman hanya menjalankan query halaman.
- Total grafik (jumlah kategori + total untuk irisan "Lainnya") dihitung dengan query terpisah tanpa GROUP BY/window dan dibatasi 5 s; bila lewat batas grafik tetap tampil tanpa total.
- Uji beban banyak user bersamaan ada di T-024.
