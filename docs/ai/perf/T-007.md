# T-007 — Perf ingest penuh termasuk tahap typed (inferensi tipe + typed-1.parquet)

- **Tanggal:** 2026-10-12
- **Mesin:** sama dengan docs/ai/perf/T-006.md (Apple M4, 16 GB, DuckDB 1.5.6, `memory_limit` 1 GB, `threads` 2).
- **Perintah:** `npx tsx --conditions=react-server scripts/perf-ingest.ts tests/fixtures/perf/teks-berat-1gb.xlsx`.
  - Skrip menjalankan `runIngest` sungguhan: raw, lalu typed per sheet.
  - Unggah hanya berupa rename lokal, sehingga waktu dari `createSheet` sampai `setTyped` ≈ waktu tahap typed sheet itu (`typedSeconds`).

## Hasil (kode final T-007, commit 2291c8a)

| Ukuran | Nilai |
|---|---|
| Waktu total (raw + typed) | **231,5 s** (3,9 menit) — load average 2,7–4,6 |
| CPU | 284 s |
| Tahap typed (3 sheet × 1.000.002 baris × 30 kolom) | **43,5 s** (± 15 s per sheet) |

| raw.parquet / typed-1.parquet | 597 MB / 599 MB |
| Tipe per sheet | 25 teks, 1 tanggal, 2 desimal, 1 bilangan bulat, 1 boolean |

Tipe per kolom sesuai model fixture (`scripts/fixtures/model.ts`):
- **No Resi:** teks.
- **Tanggal Kirim:** tanggal. Kolom ini campuran sel tanggal asli (60%), teks dd/mm/yyyy (20%), dan teks ISO (20%).
- **Ongkir:** desimal.
- **Jumlah Koli:** bilangan bulat.
- **COD** (ya/tidak): boolean.
- **Nilai Barang:** desimal. Isinya teks angka berformat ID "1.234.567,89", terdeteksi locale ID.

Run sebelumnya pada hari yang sama, saat kolom tanggal campuran masih jatuh ke teks: 316–356 s total, typed 47 s, RSS 1.029–1.550 MB, dengan load average 4–9.

## Lolos/tidak

- **T-006 AC 6** (ingest xlsx 1 GB < 15 menit, puncak RSS < 2 GB) tetap lolos dengan tahap typed: 3,9 menit dan 1.546 MB. Run terlama hari ini 5,9 menit.

## Catatan

- **Puncak RSS naik ke ± 1,5 GB.** Tahap typed membaca raw.parquet 4× (hitung baris, profil, unik pasti, COPY). DuckDB menyimpan cache halaman file sampai `memory_limit` 1 GB, ditambah heap Node sisa parse. Angka ini sesuai anggaran desain (DuckDB 1 GB per proses, RSS < 2 GB). Bila T-024 di VM minimum mendekati batas, tahap typed bisa memakai `memory_limit` lebih kecil.
- **Biaya tahap typed (± 15 s per juta baris × 30 kolom)** didominasi regex dan strptime atas 30 juta nilai dalam format long. Prafilter `datey` membuat strptime hanya dijalankan untuk nilai berbentuk tanggal.
