# T-042 — isolasi beban "Lihat data": 5 penggulir + dashboard 6 widget (10 jt baris)

Skrip: `npx tsx scripts/perf-grid.ts --dir <scratch> --reps 30 --load` (bukan bagian check).

- Mesin: container cloud sesi Claude, 4 vCPU, 16 GB RAM, Node 22.23.3 (bukan VM T-023; ulang di VM
  olympus pada P-29/T-061).
- Data: sama dengan [T-041](T-041.md): 10.000.000 baris × 30 kolom, 24 segmen, cache parquet hangat.
- Mesin query seperti produksi: memory_limit 1GB, 2 thread, 4 slot global, 2 per user, antre 10 s.
  Gerbang grid T-042: maksimal 2 slot global untuk grid, 2 in-flight per pengguna.
- Dashboard: 6 query widget agregat (count, sum, top-20 per teks, per bulan, top-20 per teks kedua,
  tabel 50 baris urut) atas satu segmen 417 rb baris, dijalankan paralel oleh satu pengguna (jatah 2),
  30 kali. Baseline = dashboard sendirian; beban = bersamaan dengan 5 penggulir yang masing-masing
  menjaga 2 jendela acak 200 × 30 in-flight terus-menerus lewat `runGridRows` + gerbang grid.

| Skenario | p95 widget | p95 satu dashboard (6 widget) | QUERY_BUSY widget |
|---|---|---|---|
| Baseline (tanpa penggulir) | 46 ms | 55 ms | 0 |
| 5 penggulir + dashboard | 68 ms | 98 ms | 0 |

Rasio p95 widget beban/baseline = 1,48× (target ≤ 2×). Baseline T-012 (Apple M4, 1 jt baris) p95 widget
36 ms; 68 ms juga ≤ 2× angka itu. Grid selama pengukuran: 112 blok sukses, 0 QUERY_BUSY.
