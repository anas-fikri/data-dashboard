## Lolos/tidak terhadap target

- **AC 1:** **lolos dengan mitigasi untuk kedua kandidat** (Vite, 3 engine). Tanpa mitigasi: AG gagal "seret ke akhir"
  di 3 engine, wheel melompati 31 (Chromium/WebKit) sampai 250 (Firefox) baris per 100 px, dan keyboard dalam di
  Firefox bisa menggulir baris terfokus keluar layar; Glide gagal "Ke baris" baris tengah di 3 engine dan baris
  terakhir terpotong di Firefox. "Ke baris 9.999.999" tepat di kedua grid dan ketiga engine.
- **AC 2:** **lolos untuk kedua kandidat**: 0 pelanggaran CSP di 3 engine; chunk AG 214,7–263,0 KiB (Vite/Next, 8
  modul s.d. set T-043), Glide 99–103 KiB, semua di bawah 293 KiB; aturan lint + test Enterprise ada di repo.
  Syarat AG: modul didaftarkan statis satu per satu, `AllCommunityModule` tidak pernah dirujuk (316–325 KiB).
- **AC 3:** **tercatat per kandidat, kecuali pembaca layar**: NVDA/VoiceOver tidak diverifikasi dan ditunda ke gerbang
  a11y T-043; ADR-0007 tetap `proposed` sampai gerbang itu lolos.

## Catatan dan rekomendasi

1. **Rekomendasi: AG Grid Community 36.2.0 (dipin persis)** — ADR-0007. Empat mitigasi wajib (kode di
   `T-035/src/AgPage.jsx`, ringkas di lampiran ADR): `wheelfix` (target float, dipasang dari `onGridReady`, tinggi baris
   dari API, horizontal dipertahankan), baris sentinel "Akhir data" + `fixbottom`, `focusguard`, dan "Ke baris"
   `'middle'`. Keempatnya **sudah diuji bersama** di 3 engine (tabel uji gabungan), tetapi label sentinel,
   `aria-rowcount`, Ctrl+Home/End, dan uji di build Next belum.
2. **Alasan AG di atas Glide** walau Glide lebih rapi menggulir: aksesibilitas DOM nyata (`aria-sort`, teks sel di DOM,
   forced-colors, zoom teks) sesuai gerbang WCAG 2.2 AA §3.7; urut, resize, geser, kolom beku, tooltip header sudah
   ada; pemeliharaan aktif dengan React 19 resmi. Glide hanya punya React 19 di alpha tanpa rilis npm 12 bulan,
   tanpa urut/saring/`aria-sort`, header dua baris harus digambar sendiri, dan `scrollTo` bawaan rusak begitu tinggi
   model melewati scroller fisik (± 1 jt baris di Chromium/WebKit, ± 560 rb di Firefox).
3. **Risiko terbuka AG — sentuh:** usapan 300 px menggeser 91–93 baris di Chromium (Firefox diperkirakan ± 750 dari
   rasio 80×, tidak diukur) dan `wheelfix` tidak mencakup sentuh. ADR-0007 menetapkan mode paging blok (50 rb baris
   per blok) untuk `any-pointer: coarse` bila uji T-043 melebihi 15 baris per usapan 300 px.
4. Uji e2e grid wajib mencakup Firefox dan dataset > 125 rb baris (stretching Firefox), dan gagal bila konsol memuat
   "AG Grid: error #200".
5. Di Turbopack, cabang mati berbasis `process.env` tidak membuang impor `AllCommunityModule` (325,1 KiB). Ukuran chunk
   rute dicek di build Next, bukan Vite.
6. Uji e2e WebKit dengan CSP produksi membutuhkan https (atau CSP dev tanpa `upgrade-insecure-requests`).

## Catatan keterlacakan data

- "16 pelanggaran tanpa `styleNonce`" dan seri seret thumb **diukur ulang** setelah data mentah putaran pertama
  tertimpa: `chromium-strict-style.json` (varian dengan/tanpa `styleNonce`) dan `chromium-ag-thumbdrag-seri.json`
  (6/6 berhenti di 9.999.994). Versi awal laporan menulis "4 dari 6" untuk seri itu; dua percobaan awal dihitung
  dengan cek batas kotak sebelum uji tumbukan `elementFromPoint` ditambahkan, jadi angka itu tidak bisa direproduksi
  dari data tersimpan dan diganti hasil ukur ulang.
- Ukuran Next Turbopack 8 modul (235,9 KiB) dan `AllCommunityModule` di cabang mati (325,1 KiB) dicatat dari keluaran
  skrip (`next16-chunks-turbopack.json` ditulis tangan dari keluaran itu); set modul T-043 (263,0 KiB) dan webpack
  tersimpan apa adanya.
- `*-wheel-step*-v1.json` = putaran pertama (akumulator bilangan bulat); `*-wheel-step*.json` = 12 langkah dengan target
  float.

## Belum diverifikasi

- **Pembaca layar NVDA / VoiceOver — ditunda ke gerbang a11y T-043** (keputusan delegasi tetap user); hanya pohon ARIA
  dan axe yang diperiksa otomatis.
- Safari, Chrome, dan Firefox rilis sungguhan (hanya build Playwright), Windows/Linux, pemetaan Ctrl+Home/End di
  Windows (semua uji keyboard memakai UA macOS), Windows High Contrast / `forced-colors`, zoom 200 %, DPR 2.
- Trackpad dan perangkat sentuh nyata, iOS/Android (sentuh hanya gestur sintetis CDP di Chromium); momentum/inersia
  dengan `wheelfix`.
- Scrollbar klasik hanya diuji di Chromium (`tests/thumbdrag.mjs`); WebKit/Firefox memakai scrollbar overlay.
