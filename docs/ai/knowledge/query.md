# Knowledge: query

- Konstruktor ParquetCache membersihkan semua yang bukan *.parquet di direktori cache (termasuk subdirektori): jangan buat cache kedua di subdirektori cache lain yang masih akan dibuka ulang — di uji, buat deps() dulu baru cache kedua; dan cache di luar allowed_directories DuckDB ditolak 'Permission Error' (sandbox bekerja). <!-- aitk:k date=2026-10-19 task=T-037 tags=query,perf -->
- Sumber sheet periode harus selalu diproyeksikan dengan _period; pemangkasan aman bila hanya membuang segmen terbukti di luar filter, dan batas atas 'detik sesudah max' harus menangani luapan tahun 9999 sebagai tanpa batas. <!-- aitk:k date=2026-10-20 task=T-058 tags=query,ui,security -->
- Show Values As dihitung sebagai lapisan di atas UNION pivot (CTE ber-window) hanya bila showAs dipakai, sehingga SQL dan kunci cache spec lama tidak berubah. <!-- aitk:k date=2026-10-21 task=T-067 tags=query,ui -->
- Cabang UNION pivot yang masing-masing membaca ulang parquet mahal pada banyak nilai — GROUPING SETS satu pindaian + label hanya untuk baris tampil memangkas 2,76× → 1,96×; max-width sel tabel w-max diabaikan, batasi lewat kotak isi. <!-- aitk:k date=2026-10-21 task=T-070 tags=query,ui -->
- Top N pivot = ganti kunci level jadi NULL + penanda x<level> di kunci kelompok (rantai CTE sebelum src): semua agregat sesudahnya otomatis benar untuk agregat non-aditif dan field terhitung. <!-- aitk:k date=2026-10-21 task=T-071 tags=query,ui -->
