- DuckDB 1.5 dengan tabel lebar punya biaya tetap per kolom: penulis Parquet menyiapkan buffer STRING_DICTIONARY_PAGE_SIZE_LIMIT (± 1 MB) per kolom string, dan tabel menahan satu segmen blok (256 KiB) per kolom. Window row_number(), top-N SELECT * ORDER BY LIMIT, dan hash join dengan sisi build lebar OOM jauh sebelum 1.000 kolom di 1 GB. Pola aman: CTAS dengan parallel=false + rowid sebagai nomor urut, ASOF JOIN sempit + POSITIONAL JOIN, list_filter untuk hitungan per kolom, batas kamus per lebar, dan DB ber-blok 16 KiB hanya untuk tabel lebar (> 256 kolom). <!-- aitk:k date=2026-10-12 task=T-006 tags=security -->
