# Knowledge: ui

- UI: wajib pakai plugin frontend-expert (/frontend-expert:ui|design|polish|audit|test-ui) untuk semua komponen/halaman; icon hanya @tabler/icons-react (cek registry tabler-icons skill dulu), Lucide hanya fallback bila Tabler tidak punya. Keputusan user 2026-10-11. <!-- aitk:k date=2026-10-11 tags=ui,conventions source=manual pin -->
- Grid virtual dengan jutaan baris di browser terbentur batas tinggi elemen (Chromium/WebKit 33.554.428 px, Firefox ± 17,9 jt px; AG Grid memakai 32 jt / 4 jt px) sehingga gulir 'diregangkan' 10×/80×: wheel, seret ke akhir, ke-baris, dan fokus keyboard dalam perlu koreksi sendiri dan diuji di ketiga engine; di sentuh lebih aman paging blok ≤ floor((4.000.000 − viewport)/tinggi baris). <!-- aitk:k date=2026-10-17 task=T-035 tags=ui,spike,adr -->
- AG Grid v36: defaultColDef/columnDefs harus stabil antar render, kalau tidak AG menerapkan ulang kolom dan membuang beku/lebar pengguna; dan klien grid tidak boleh mengirim potongan kolom paralel melebihi jatah in-flight per user di server. <!-- aitk:k date=2026-10-20 task=T-043 tags=ui -->
- Dialog Radix yang ditutup dengan mengosongkan prop target memanggil onCloseAutoFocus setelah target null — simpan target terakhir; dan setiap pergantian tampilan grid wajib mengosongkan jumlah baris agar galat/timeout tidak menampilkan angka tampilan lama. <!-- aitk:k date=2026-10-20 task=T-044 tags=ui,api -->
- Ringkasan grid harus memakai measureExpr KPI agar angkanya identik dengan widget; salin satu sel juga harus dikutip TSV, kalau tidak teks multi-baris dipecah Excel menjadi sel/formula. <!-- aitk:k date=2026-10-20 task=T-045 tags=ui,security -->
- Tampilan besar untuk viewer harus memakai ulang jalur widget (body ⊆ widgetId/dashboardFilters/page/sort) dan tidak mengimpor komponen grid, agar D6 dan anggaran chunk dashboard tetap terjaga. <!-- aitk:k date=2026-10-20 task=T-047 tags=ui,security -->
- AG Community tidak memasang aria-selected untuk pilihan non-AG — pasang sendiri lewat processRowPostCreate + refresh saat pilihan berubah; axe disuntik lewat page.evaluate agar CSP nonce tidak menghalangi. <!-- aitk:k date=2026-10-20 task=T-048 tags=ui,a11y,responsive -->
- Job yang memanggil commit lalu gagal (koneksi putus) tidak boleh menghapus objek segmen — status commit tak pasti; dan penerapan hasil tinjauan harus membawa digest tinjauan, bukan menghitung ulang diam-diam terhadap versi aktif yang mungkin sudah berganti. <!-- aitk:k date=2026-10-20 task=T-051 tags=ui,data-integrity,security -->
- Pilihan unggahan (mode + label) harus ikut status panel dan unggahan tertunda dan tidak boleh diturunkan diam-diam: PERIOD tanpa versi dasar = jangan kirim, lanjut 'ganti semua' tertunda dari dropzone periode = konfirmasi ulang. <!-- aitk:k date=2026-10-20 task=T-053 tags=ui,upload -->
- Segmen berlabel menyimpan min/max kolom tanggal acuan (bukan rentang periode) di Segment.minDate/maxDate — pemangkasan harus memakai periodStart/periodKey untuk segmen itu. <!-- aitk:k date=2026-10-20 task=T-054 tags=ui,data-safety,a11y -->
- Hapus/pulihkan periode cukup menulis manifest versi baru di bawah lock Dataset; pulihkan hanya aman bila tanda tangan tipe kolom sama, dan dialog harus menampilkan perubahan per sheet karena sheet tanpa periode itu di versi sumber kehilangan barisnya. <!-- aitk:k date=2026-10-20 task=T-056 tags=ui,data-safety,security -->
- Penyusun rumus berbasis token harus diurai ke pohon yang sama dengan validasi server; angka ketikan harus mengikuti konvensi id-ID secara eksplisit — '0.125' bukan ribuan. <!-- aitk:k date=2026-10-21 task=T-069 tags=ui -->
- Playwright menganggap aria-disabled tidak bisa diklik — uji tombol aria-disabled lewat focus + Enter; urungkan hapus widget terikat harus mengikat ulang, bukan memulihkan spec efektif. <!-- aitk:k date=2026-10-21 task=T-074 tags=ui -->
