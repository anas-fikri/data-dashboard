- Di xlsxSheetsParallel, RawSheetWriter.finish berjalan di dalam antrean DuckDB FIFO — menahan finish di tes memblokir semua sheet; untuk memaksa urutan selesai, tahan job.done (pembacaan worker) yang ada di luar antrean. <!-- aitk:k date=2026-10-18 task=T-pbz0 tags=bug -->
- docker-compose.prod.yml bernama 'dashboard': setiap salinan di VM yang sama WAJIB -p sendiri, dan docker load berbagi image store dengan produksi — arsip bertag sama (mis. latest) diam-diam memindahkan tag produksi, jadi catat ID image produksi sebelum load. <!-- aitk:k date=2026-10-19 task=T-tqse -->
- rclone sftp (Go knownhosts) menolak bila tipe kunci host yang dinegosiasikan berbeda dari yang dipin: pin kunci dari Tes koneksi lalu set RCLONE_CONFIG_<remote>_HOST_KEY_ALGORITHMS ke tipe kunci itu (ssh-rsa → rsa-sha2-512 rsa-sha2-256 ssh-rsa); server SFTP tiruan in-process (ssh2 Server) hanya bisa dipakai dari proses yang sama dengan spawn async — spawnSync memblokir event loop sehingga server tidak menjawab. <!-- aitk:k date=2026-10-19 task=T-y8qq tags=security -->
- Role aplikasi di PostgreSQL host olympus tidak punya CREATEDB/superuser: membuat ulang database (mis. ganti encoding) harus lewat sudo -u postgres oleh pemilik server dari terminal interaktif — '!' di sesi Claude tidak punya TTY untuk password sudo. <!-- aitk:k date=2026-10-19 task=T-y3y1 -->
- SFTP Synology: file kecil (≤ ±2 KB) tetap masuk walau volume/kuota penuh karena Btrfs menyimpannya inline di metadata — tes koneksi berbasis file kecil tidak membuktikan ruang cukup; FAILURE saat menulis file ≥ 4 KB = penyimpanan/kuota habis. <!-- aitk:k date=2026-10-19 task=T-h77x tags=security -->
- Arsip kode dari folder aplikasi produksi wajib --exclude='./.env.prod*' (cadangan seperti .env.prod.bak-* ikut bila hanya ./.env.prod yang dikecualikan) dan dibuat dengan umask 077 — /data/docker-data bisa dibaca user lain di VM bersama. <!-- aitk:k date=2026-10-19 task=T-sew3 -->
- Refine keunikan di spec widget harus mengecualikan MISSING_COLUMN: remap/allMissing bisa memberi penanda yang sama ke beberapa isian, dan spec yang gagal parse membuat widget kosong permanen (activation menyimpannya ke DB). <!-- aitk:k date=2026-10-19 task=T-686n -->
- Tabel dengan border-collapse: border pada sel thead/tfoot yang sticky ikut tergulir — pakai box-shadow inset untuk garis kepala/kaki/kolom menempel; dan setiap jenis widget baru wajib didaftarkan di PHONE_HEIGHT (layout-ops) serta MIN_BY_TYPE, kalau tidak kartu ponsel jatuh ke 160 px. <!-- aitk:k date=2026-10-19 task=T-tcjp -->
- Popover di dalam Radix Dialog modal harus modal juga (Popover modal): tanpa itu RemoveScroll milik Dialog memblokir gulir roda/sentuh di daftar popover yang di-portal. <!-- aitk:k date=2026-10-19 task=T-jwhc -->
- Saat APP_URL dipindah ke domain, setiap cek Origin yang membandingkan dengan APP_URL saja langsung mematikan akses lewat IP — origin sah harus berupa daftar (appOrigins: APP_URL + APP_LAN_URL); untuk uji produksi tanpa login pakai POST /api/auth/login dengan body rusak (origin dicek sebelum rate limit dan sebelum login), karena route API lain dijawab 401 oleh proxy.ts sebelum cek origin. <!-- aitk:k date=2026-10-19 task=T-9t9b tags=security -->
- edge-tts bisa menggantung tanpa galat: panggil dengan timeout dan tulis ke berkas .part lalu rename, kalau tidak proses yang dimatikan meninggalkan mp3 rusak yang dianggap cache valid (rekaman gagal di ffprobe). <!-- aitk:k date=2026-10-19 task=T-9bc2 -->
- Typed segmen menambah kolom _src_row: pembaca yang memakai indeks kolom posisi (sampel skema, helper uji SELECT *) harus memilih kolom eksplisit — di DuckDB COLUMNS('^_(src_)?row$') membaca _row dan _src_row bila ada, jadi satu SQL melayani typed lama dan baru. <!-- aitk:k date=2026-10-19 task=T-036 tags=data-model,migration -->
- Konstruktor ParquetCache membersihkan semua yang bukan *.parquet di direktori cache (termasuk subdirektori): jangan buat cache kedua di subdirektori cache lain yang masih akan dibuka ulang — di uji, buat deps() dulu baru cache kedua; dan cache di luar allowed_directories DuckDB ditolak 'Permission Error' (sandbox bekerja). <!-- aitk:k date=2026-10-19 task=T-037 tags=query,perf -->
- Filter periode cukup sebagai rentang setengah terbuka [awal, awal periode berikutnya) — bentuk yang sudah dipakai filter silang grafik, benar untuk DATE dan TIMESTAMP tanpa jenis filter baru; labelnya diturunkan kembali dari rentang (calendarPeriod), jadi URL lama/baru tetap kompatibel. <!-- aitk:k date=2026-10-19 task=T-9gs1 -->
- Saringan pembaca pada widget sebaiknya merujuk PERAN field widget itu (row0/row1/column) + nama kolom/grain saat dibuat, bukan kolom bebas: D6 tetap utuh tanpa daftar izin baru, dan URL/ekspor lama tidak diam-diam menyaring kolom pengganti; sumber filter silang baru harus opt-in (crossFilter === true) agar dashboard yang sudah dibagikan tidak tiba-tiba membuka kolom filter viewer. <!-- aitk:k date=2026-10-19 task=T-f4a7 -->
- GC berbasis referensi aman bila tiga hal dipegang bersama: aturan hidup yang konservatif (status ≠ FAILED, termasuk versi pembuat yang masih diproses), tenggang waktu sejak tidak dirujuk, dan pemeriksaan ulang rujukan tepat sebelum objek dihapus; jalur kegagalan harus mengubah status lebih dulu (UPDATE berpenjaga) dan menghapus hanya bila peralihan itu berhasil, kalau tidak job yang dinyatakan gagal setelah commit-nya masuk menghapus versi hidup. <!-- aitk:k date=2026-10-19 task=T-038 tags=data-safety,storage -->
