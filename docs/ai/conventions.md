# Conventions

- Stack and versions: Next.js 15 App Router + TypeScript strict; Node 22 LTS; Prisma + PostgreSQL 16; MinIO (S3); DuckDB via @duckdb/node-api; BullMQ + Redis 7; ECharts; Tailwind; @tabler/icons-react (Lucide hanya fallback, jangan campur dalam satu komponen).
- Structure: `src/app` (routes), `src/features/<domain>` (auth, datasets, versions, ingest, schema, query, dashboards, widgets, filters, sharing, exports, guides, admin), `src/lib` (shared infra: db, storage, queue, duckdb, cache), `worker/` (ingest + ekspor tabular, proses terpisah, share `src/lib`), `renderer/` (PDF, Chromium), `prisma/` (schema + migrations), `scripts/` (fixture, perf), `tests/` mirror `src/`, `tests/fixtures/` (kecil, di-commit) dan `tests/fixtures/perf/` (gitignored).
- Naming and style: ESLint + Prettier default Next; file kebab-case, komponen PascalCase, fungsi camelCase; UI text Bahasa Indonesia, kode & komentar English.
- Errors: Server Action mengembalikan `{ ok: false, code, message }` (kode: NOT_FOUND, FORBIDDEN, RATE_LIMITED, DATASET_BUSY, INVALID_FORMAT, FILE_TOO_LARGE, QUOTA_EXCEEDED, LIMIT_REACHED, QUERY_TIMEOUT, EXPORT_TOO_LARGE, LAST_ADMIN, …) dan tidak melempar; Route Handler memakai HTTP status (404/403/429/400). Objek yang tidak boleh diakses selalu NOT_FOUND/404, bukan 403. Log terstruktur (pino) dengan jobId/datasetId/versionId; pesan user Bahasa Indonesia yang bisa ditindak.
- Data: data tabular di Parquet (object storage), BUKAN di PostgreSQL; per sheet `raw.parquet` (posisional, VARCHAR, semua baris) + `typed-<schemaRevision>.parquet`; metadata di PostgreSQL. Waktu METADATA disimpan UTC dan ditampilkan Asia/Jakarta; nilai TANGGAL DATASET naive (DATE/TIMESTAMP tanpa zona) dan tidak pernah digeser. Enum status di kode English (UPLOADING, UPLOADED, INGESTING, AWAITING_MAPPING, READY, FAILED), label UI Indonesia. ID cuid; ukuran file dalam byte; angka uang DECIMAL(38,6), jangan float; format Rupiah `Rp 1.234.568` dengan spasi biasa.
- Tests: Vitest (unit + integration), Playwright (e2e jalur kritis); setiap fitur punya test terhadap fixture kecil (≤ 50k baris) dari `scripts/make-fixture.ts` di `tests/fixtures/`; `npm run check` (lint + typecheck + test) harus < 3 menit dan tidak menyentuh fixture perf. AC performa dibuktikan dengan `npm run perf` dan laporan `docs/ai/perf/<task>.md` yang dicatat sebagai evidence task.
- Security: Auth.js Credentials (argon2id) + JWT dengan `sessionVersion` dicek ke DB tiap permintaan; registrasi whitelist domain + verifikasi email; semua akses dicek di server (pemilik/share/isAdmin). Upload: ekstensi, signature (xlsx ZIP; csv teks tanpa NUL, UTF-16 ditolak), ListParts + HeadObject untuk batas ukuran, fingerprint di-scope user+dataset. Query: non-pemilik hanya `{widgetId, filters}`; spec divalidasi zod terhadap skema, identifier dikutip dari skema, nilai parameter binding, tidak ada SQL dari client. Markdown panduan disanitasi. Secrets hanya env.
- Git and versioning: Conventional Commits; aitk release for versions and the changelog
- UI consistency: SEMUA pekerjaan UI (komponen, layout, halaman, polish, audit) WAJIB lewat plugin frontend-expert (skill /frontend-expert:ui, :design, :polish, :audit, :test-ui) — jangan hand-roll UI tanpa plugin. Icon HANYA @tabler/icons-react (`size={20} stroke={1.5}`), cek registry ~/.agents/skills/tabler-icons/references/icon-registry.json sebelum import, Lucide dilarang kecuali Tabler tidak punya ikon. Token warna Tailwind di tailwind.config; grid dashboard 12 kolom; jangan hardcode hex di komponen.
