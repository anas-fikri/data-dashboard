# Conventions

- Stack and versions: Next.js 16 App Router (Turbopack) + React 19 + TypeScript strict; Node ≥ 22 (.nvmrc 22); Prisma dipin 6.12.0 (6.13–8.x membawa deepmerge-ts rentan, lihat T-001) + PostgreSQL 16; object storage S3 RustFS (ADR-0002, klien S3 wajib requestChecksumCalculation WHEN_REQUIRED); DuckDB via @duckdb/node-api; BullMQ + Redis 7; ECharts; Tailwind; @tabler/icons-react (Lucide hanya fallback, jangan campur dalam satu komponen).
- Structure: `src/app` (routes), `src/features/<domain>` (auth, datasets, versions, ingest, schema, query, dashboards, widgets, filters, sharing, exports, guides, admin), `src/lib` (shared infra: db, storage, queue, duckdb, cache), `worker/` (ingest + ekspor tabular, proses terpisah, share `src/lib`), `renderer/` (PDF, Chromium), `prisma/` (schema + migrations), `scripts/` (fixture, perf), `tests/` mirror `src/`, `tests/fixtures/` (kecil, di-commit) dan `tests/fixtures/perf/` (gitignored).
- Naming and style: ESLint + Prettier default Next; file kebab-case, komponen PascalCase, fungsi camelCase; UI text Bahasa Indonesia, kode & komentar English.
- Errors: Server Action mengembalikan `{ ok: false, code, message }` (kode: NOT_FOUND, FORBIDDEN, RATE_LIMITED, DATASET_BUSY, INVALID_FORMAT, FILE_TOO_LARGE, QUOTA_EXCEEDED, LIMIT_REACHED, QUERY_TIMEOUT, EXPORT_TOO_LARGE, LAST_ADMIN, …) dan tidak melempar; Route Handler memakai HTTP status (404/403/429/400). Objek yang tidak boleh diakses selalu NOT_FOUND/404, bukan 403. Log terstruktur (pino) dengan jobId/datasetId/versionId; pesan user Bahasa Indonesia yang bisa ditindak.
- Data: data tabular di Parquet (object storage), BUKAN di PostgreSQL; per sheet `raw.parquet` (posisional, VARCHAR, semua baris) + `typed-<schemaRevision>.parquet`; metadata di PostgreSQL. Waktu METADATA disimpan UTC dan ditampilkan Asia/Jakarta; nilai TANGGAL DATASET naive (DATE/TIMESTAMP tanpa zona) dan tidak pernah digeser. Enum status di kode English (UPLOADING, UPLOADED, INGESTING, AWAITING_MAPPING, READY, FAILED), label UI Indonesia. ID cuid; ukuran file dalam byte; angka uang DECIMAL(38,6), jangan float; format Rupiah `Rp 1.234.568` dengan spasi biasa.
- Tests: Vitest (unit + integration), Playwright (e2e jalur kritis); setiap fitur punya test terhadap fixture kecil (≤ 50k baris) dari `scripts/make-fixture.ts` di `tests/fixtures/`; `npm run check` (lint + typecheck + test) harus < 3 menit dan tidak menyentuh fixture perf. AC performa dibuktikan dengan `npm run perf` dan laporan `docs/ai/perf/<task>.md` yang dicatat sebagai evidence task.
- Security: Auth.js Credentials (argon2id) + JWT dengan `sessionVersion` dicek ke DB tiap permintaan; registrasi whitelist domain + verifikasi email; semua akses dicek di server (pemilik/share/isAdmin). Upload: ekstensi, signature (xlsx ZIP; csv teks tanpa NUL, UTF-16 ditolak), ListParts + HeadObject untuk batas ukuran, fingerprint di-scope user+dataset. Query: non-pemilik hanya `{widgetId, filters}`; spec divalidasi zod terhadap skema, identifier dikutip dari skema, nilai parameter binding, tidak ada SQL dari client. Markdown panduan disanitasi (rehype-sanitize allowlist). Setiap Server Action/Route Handler/layout memanggil requireUser()/requireAdmin() Node-side; isAdmin dari DB. Token (verifikasi/reset) 32 byte acak, disimpan hash, sekali pakai, kedaluwarsa. ContentType objek storage ditetapkan server. CSV ekspor menetralkan formula. Secrets hanya env; task bertag security berprofil strict dan wajib checklist ASVS.
- Audit dependensi: `npm run audit` = produksi level high + semua level critical; `aitk audit` (osv-scanner + npm audit + secret scan) wajib hijau sebelum close. Pengecualian hanya lewat osv-scanner.toml dengan alasan + ignoreUntil dan dicatat di task; lebih baik lepas dependency pembawa (contoh: eslint-config-next dilepas karena braces).
- Git and versioning: Conventional Commits; aitk release for versions and the changelog
- UI consistency: SEMUA pekerjaan UI WAJIB lewat plugin frontend-expert dengan rantai: design-direction (hanya T-025 / layar baru ambigu) → design-foundations → tokens → (+forms / data-fetching / app-shell) → components → anti-slop-code → responsive → motion → anti-slop-design → polish → accessibility; sebelum DONE isi blok Conventions check (references/compliance-gates.md) dan jalankan /frontend-expert:audit tanpa Critical/High. Token preset dan arah desain ditetapkan sekali di T-025 dan dicatat di docs/ai/design-system.md; komponen memakai CSS custom properties, tidak ada hex mentah. Icons: HANYA @tabler/icons-react (`size={20} stroke={1.5}`) sebagai waiver resmi atas default Reicon plugin; Lucide hanya bila Tabler tidak punya ikon dan tidak dicampur dalam satu komponen; cek registry ~/.agents/skills/tabler-icons/references/icon-registry.json sebelum import. Shell: tema sebagai ikon di topbar, avatar → menu akun, sidebar drawer + backdrop <768, CTA utama full-width <768, select kustom untuk filter. Chart via skill dataviz dengan palet dari token. Grid dashboard 12 kolom.
