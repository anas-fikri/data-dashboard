## Persiapan

1. **Prasyarat**: rilis **v1.3.0** (G-7) terpasang di olympus lewat `deploy/upgrade.sh` (runbook-deploy §7,
   backup DB otomatis sebelum migrasi `20261021170000_t072_saved_pivot`) — Skenario D2. Tanpa itu, jalankan UAT
   di lingkungan dev/stack uji dan tulis di "Lingkungan".
2. Seed panduan (sekali, setelah rilis). Dua artikel baru terbit dengan seed biasa; empat artikel lama yang ikut
   berubah ditimpa hanya bila diminta (suntingan admin di artikel lain aman):
   - `docker compose -f docker-compose.prod.yml run --rm worker node_modules/.bin/tsx --conditions=react-server scripts/seed-guides.ts`
   - `docker compose -f docker-compose.prod.yml run --rm worker node_modules/.bin/tsx --conditions=react-server scripts/seed-guides.ts --update --only widget-pivot,editor-ubah-dashboard,viewer-lihat-filter-ekspor,mengenal-data-dashboard`
3. Tiga akun: **pemilik** (akun Anda), **editor** dan **viewer** (akun uji non-admin).
4. Data contoh: unggah `docs/ai/uat/T-076-contoh.csv` (20 baris) sebagai dataset baru **UAT G-7**. Kolom:
   _Wilayah, Kota, Layanan, Tanggal, No Kiriman, Pendapatan, Biaya_. Periksa di skema: _Tanggal_ = tanggal,
   _Pendapatan_ dan _Biaya_ = angka bulat, _No Kiriman_ = teks. Ciri data yang sengaja dibuat:
   - kiriman **K008** tercatat di **2 baris** (Bandung, Feb) → _Jumlah baris_ 20, _Jumlah unik No Kiriman_ 19;
   - **Kediri** berpendapatan **0** → margin Kediri harus "–" (dibagi nol);
   - Jawa Barat punya 4 kota, Jawa Timur 3 kota → cocok untuk N teratas + (Lainnya).

   disebut lain. Kartu sempit bisa menampilkan angka ringkas (mis. "Rp 21,8 jt"); arahkan kursor untuk angka

## Bagian B — Field terhitung (T-068, T-069)

## Scenario B1 — Margin dan rata-rata per kiriman di pivot

Langkah: widget **Pivot** baru: **Satu baris per** _Wilayah_, **Dirinci per** _Kota_, Nilai 1 = **Total**
_Pendapatan_. Tekan **Tambah field terhitung**:

## Scenario B2 — Penyusun rumus: galat, keyboard, angka Indonesia

sentuh cukup besar, fokus tidak hilang setelah simpan/batal.

## Scenario F3 — Keputusan target query pivot dingin (T-hfqf)

Konteks: target rencana p95 ≤ 3 s pada 10 jt baris hanya tercapai untuk permintaan dari cache (2–6 ms).
