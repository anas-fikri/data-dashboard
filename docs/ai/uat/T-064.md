# Uji penerimaan pengguna (UAT): T-064 — Lihat data dan data per periode

Penguji (pemilik): 
Tanggal: 
Lingkungan / versi (URL + commit dari `git rev-parse --short HEAD` di folder aplikasi server): 

Singkatan: **UAT** (user acceptance test, uji penerimaan pengguna), **AC** (acceptance criteria, kriteria
penerimaan), **VM** (virtual machine, server olympus), **e2e** (uji otomatis ujung-ke-ujung di browser),
**p95** (waktu respons persentil ke-95), **ADR** (catatan keputusan arsitektur).

Cara pakai: jalankan setiap skenario seperti pengguna biasa, bandingkan dengan **Hasil yang diharapkan**, lalu
centang Pass (lulus) atau Fail (gagal) dan tulis yang terlihat di **Teramati**. Temuan yang menghambat
(nilai salah, data hilang, keamanan, aksesibilitas penghambat) → Fail; temuan kosmetik → tulis saja, tetap Pass.
Hanya pemilik yang boleh memutuskan Terima/Tolak di bagian akhir — agen AI tidak pernah menerima UAT.

## Persiapan

1. **Prasyarat produksi**: rilis G-6 sudah terpasang di olympus (Skenario D6). Tanpa itu, jalankan UAT di
   lingkungan dev/stack uji dan tulis di "Lingkungan".
2. Seed panduan baru di server (sekali, setelah rilis; hanya artikel yang berubah/baru, suntingan admin di artikel
   lain aman):
   `docker compose -f docker-compose.prod.yml run --rm worker node_modules/.bin/tsx --conditions=react-server scripts/seed-guides.ts --update --only lihat-data-seperti-excel,data-per-periode,editor-ubah-dashboard,viewer-lihat-filter-ekspor,ganti-data-pemetaan`
   (`--update` menimpa isi kelima artikel itu dengan versi repo; artikel baru terbit di urutan terakhir).
3. Tiga akun: **pemilik** (akun Anda), **editor** dan **viewer** (akun uji non-admin) — bagikan satu dashboard
   ke editor sebagai Editor dan ke viewer sebagai Viewer.
4. Data uji:
   - Dataset **A** (biasa): satu file ≥ 450 baris dengan kolom teks, angka, tanggal, dan Ya/Tidak; sebaiknya
     ada satu sel angka berisi teks (mis. `12a`) agar ada sel "tidak terbaca".
   - Empat file laporan bulanan berkolom sama dengan kolom tanggal: **Jan**, **Feb**, **Mar**, **Apr 2026**
     (mis. `laporan_2026-01.csv` … `laporan_2026-04.csv`), ditambah **Feb-kecil** (isi Februari < 50% baris
     Feb) dan **Mar-nyasar** (isi Maret + 2–3 baris bertanggal 28 Februari).
   - Dataset **B** (untuk data per periode): mulai dari file **Jan** saja.
5. Siapkan Excel di komputer yang sama untuk uji tempel.
