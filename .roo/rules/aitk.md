# aitk

This repository uses aitk. Follow the "Working in this repository (aitk)" section of AGENTS.md:
run `aitk brief` first, take a task with `aitk task next --start` (or continue the active one), run `aitk check`
until it passes, then `aitk close --summary "…" --knowledge "…|none"`. If the aitk MCP tools are available, they do the same.
